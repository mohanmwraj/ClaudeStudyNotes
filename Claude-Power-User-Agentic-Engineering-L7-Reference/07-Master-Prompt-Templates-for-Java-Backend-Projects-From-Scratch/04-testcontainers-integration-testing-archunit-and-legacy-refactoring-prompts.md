## 0. Orientation

Tests generated by an assistant fail in a characteristic way: they pass. They pass on the buggy code too. They assert that no exception was thrown, run a "concurrency test" once on a quiet machine, and mock the database whose behaviour is the point.

Both templates here are built around one demand, a **test that is shown to fail before it is allowed to pass**:
- T5 makes every race test fail against the unfixed code (INV-CONC-2).
- T6 makes characterization tests pass on the *unchanged* legacy code first (INV-LEG-1), and freezes architecture debt so it can only shrink (INV-LEG-3).

### 0.1 The twelve rules

1. **A race test asserts a domain invariant after every round.** "Successes ≤ stock and the books balance" is an invariant; "no exception" isn't. [L1]
2. **Release threads together with a `CyclicBarrier`, repeat for R rounds, count failing rounds.** One run proves nothing about an interleaving. [L1]
3. **Widen the window with a test-only seam.** The same check-then-act bug failed **200/200** rounds with a 0.2 ms seam between read and write, and only **1–2/200** without it. A test that fails by luck will pass by luck in CI. [measured: L1]
4. **The fix must pass the same attack, seam included.** `ConcurrentHashMap.compute` and a CAS loop (seam between read and `compareAndSet`) both gave 0/200. [measured: L1]
5. **A thread-safe map doesn't make your logic atomic.** `ConcurrentHashMap` `get` then `put` is the bug, not the fix. [L1]
6. **Use JMH for micro-benchmarks:**
   - two or more forks, warmup and measurement iterations, `Blackhole` for results;
   - report the score *with its error*;
   - never `System.nanoTime` loops;
   - use jcstress when the question is the Java Memory Model rather than your invariant.

   [doc: JMH/jcstress + practice]
7. **On a JDK 21 runtime, look for virtual-thread pinning** (`synchronized` around blocking I/O) with the JFR event `jdk.VirtualThreadPinned`. JDK 24+ removed `synchronized` pinning (JEP 491). [doc: JEP 491]
8. **Characterize before you refactor.** Record the legacy code's current outputs against real PostgreSQL and Kafka (Testcontainers), quirks included, and get them green on the unchanged code first. [practice: characterization testing]
9. **Encode the target architecture as ArchUnit rules over bytecode.** L2's layer rule passes the clean codebase and reports the legacy violations precisely: `Order.toRow()` calls `OrderRow.<init>`, and `OrderPricing.price` takes a `java.sql.Connection`. [measured: L2]
10. **Freeze the debt with `FreezingArchRule`, so it can only shrink.**
    - The first run on legacy passed and stored 5 violations.
    - A *new* violation failed on its own.
    - Fixing `Order.toRow` shrank the store from 5 to 3.

    Commit the store (`archunit_store/`); never edit it by hand. [measured: L2]
11. **Integration tests run real infrastructure.** Testcontainers 2.0.5 (Boot-managed) with `@ServiceConnection`, image tags pinned, no H2 standing in for PostgreSQL. [doc: Spring Boot, Testcontainers]
12. **Behaviour changes are separate commits from refactorings.** A snapshot update without a reason in the report is a hidden behaviour change. [practice]

## 1. First principles

### 1.1 Why the seam matters: measured [L1]

| Variant | Failing rounds (of 200) | What it means |
|---|---|---|
| check-then-act, 0.2 ms seam | 200 | The test **reliably** catches the bug |
| check-then-act, no seam | 1–2 (varies by run) | Catches it *sometimes*; on a different CI machine, maybe never |
| `ConcurrentHashMap.compute` | 0 | The fix holds |
| CAS loop with the seam inside | 0 | The fix holds even with the window held open |

The racy rows vary run to run by nature (the gate allows exactly those lines to differ). The fixed rows must be 0 every run.

The seam is a production no-op: a `Runnable` injected at construction that tests replace with a `parkNanos`. It is the cheapest form of the systematic-interleaving idea behind tools like jcstress and Lincheck. T5 step 3 asks for it explicitly.

### 1.2 What a JMH benchmark must report [doc: JMH]

For "does the CAS version keep p99 `reserve()` under 50 µs at 16 threads":
- `@State(Scope.Benchmark)` for the shared inventory, `@Threads(16)`, `@Fork(2)`, `@Warmup` and `@Measurement` iterations;
- `@BenchmarkMode(Mode.SampleTime)` for latency percentiles;
- results consumed through `Blackhole`.

The report quotes score ± error from the JMH table. A single-fork number with no error column is an anecdote. JMH 1.37 is the current release on Maven Central [measured]. It was not executed in this harness; T5's verification runs it in your build.

### 1.3 Characterization tests: freeze behaviour, not intentions [practice]

Legacy code's specification is its current behaviour, bugs included. T6's `known_behaviour` variable lists the quirks you *know about*, for example "cancelling a SHIPPED order returns 200 and does nothing". The characterization tests discover the rest by recording outputs for a matrix of inputs against real infrastructure.

Each later commit either keeps every snapshot green (a refactoring) or changes some snapshots with a stated reason (a behaviour change, in its own commit).

Real infrastructure matters because legacy behaviour lives in the database: SQL dialect, NULL handling, transaction isolation and triggers. H2 in PostgreSQL mode differs on exactly those, which is why INV-LEG-4 forbids it.

### 1.4 ArchUnit on bytecode, and the freeze ratchet [measured: L2]

ArchUnit reads compiled classes. So its rules see what the code *does*, method calls, constructor calls, return types, parameter types, not what the imports say. L2's legacy variant shows the precision:
- **Layers rule, 2 violations:** `Order.toRow()` both *calls* `OrderRow.<init>` and *returns* `OrderRow`.
- **Purity rule, 3 violations:** `OrderPricing.price` takes a `java.sql.Connection` parameter, calls `getNetworkTimeout()`, and declares `SQLException`.

`FreezingArchRule.freeze(rule)` turns any rule into a ratchet:
1. **First evaluation:** stores today's violations and passes.
2. **Later evaluations:** fail only on violations not in the store.
3. **Fixed violations:** removed from the store automatically.

In L2: the store held 5, the new `Refund → PlaceOrder` violation failed alone, and the `toRow` fix brought the store to 3. In a repository the default store is text files under `archunit_store/`, committed, so the PR diff shows debt shrinking. T6's verification runs `git diff --stat archunit_store/`, which must only ever remove lines. L2 uses an in-memory `ViolationStore` to stay self-contained.

## 3. Verified listings

### L1 · `RaceHarness.java`

**What it shows.**
- Eight threads, released together by a `CyclicBarrier`, each call `reserve("sku-1", 1)` against a stock of 5, for 200 rounds.
- After each round the harness checks that successes ≤ stock and that available stock equals stock minus successes.
- Four variants: the check-then-act bug with and without the widening seam, `ConcurrentHashMap.compute`, and a CAS loop with the seam inside.
- The harness classifies itself: whether the test *caught* the bug, and whether a fix *holds*.

**What it does not show.** Java Memory Model reorderings (that is jcstress), database-level races (T5 points those at a unique constraint or `SELECT … FOR UPDATE`), and throughput (that is JMH).

Run: `java RaceHarness.java` (JDK 21+).

```java
// RaceHarness.java - T5's harness in miniature: 8 threads released together by a CyclicBarrier call reserve() once per
// round for 200 rounds, and the invariant (no oversell, no lost update) is checked after every round. A test-only seam
// widens the window between read and write. The harness must fail on check-then-act (INV-CONC-2) and pass on the fixes,
// seam included. Plain JDK; the counts for the racy variants vary run to run by nature, the fixed ones must be 0.
import java.util.ArrayList;
import java.util.List;
import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.CyclicBarrier;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;
import java.util.concurrent.Future;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.locks.LockSupport;
import java.util.function.Function;

public final class RaceHarness {
    static final int THREADS = 8, ROUNDS = 200, STOCK = 5;
    static final Runnable NO_SEAM = () -> {};
    static final Runnable WIDEN = () -> LockSupport.parkNanos(200_000);   // test-only: 0.2 ms between read and write

    interface Inventory {
        boolean reserve(String sku, int qty);
        int available(String sku);
    }

    /** The bug: a thread-safe map does not make read-check-write atomic. */
    static final class CheckThenAct implements Inventory {
        private final Map<String, Integer> stock = new ConcurrentHashMap<>(Map.of("sku-1", STOCK));
        private final Runnable seam;
        CheckThenAct(Runnable seam) { this.seam = seam; }
        public boolean reserve(String sku, int qty) {
            int have = stock.getOrDefault(sku, 0);
            if (have < qty) {
                return false;
            }
            seam.run();
            stock.put(sku, have - qty);
            return true;
        }
        public int available(String sku) { return stock.get(sku); }
    }

    /** Fix 1: ConcurrentHashMap.compute runs the read-modify-write atomically for the key. */
    static final class AtomicCompute implements Inventory {
        private final Map<String, Integer> stock = new ConcurrentHashMap<>(Map.of("sku-1", STOCK));
        public boolean reserve(String sku, int qty) {
            boolean[] ok = {false};
            stock.compute(sku, (k, have) -> {
                if (have == null || have < qty) {
                    return have;
                }
                ok[0] = true;
                return have - qty;
            });
            return ok[0];
        }
        public int available(String sku) { return stock.get(sku); }
    }

    /** Fix 2: a CAS loop; the seam sits between read and compareAndSet and the loop absorbs it. */
    static final class CasLoop implements Inventory {
        private final Map<String, AtomicInteger> stock = new ConcurrentHashMap<>(Map.of("sku-1", new AtomicInteger(STOCK)));
        private final Runnable seam;
        CasLoop(Runnable seam) { this.seam = seam; }
        public boolean reserve(String sku, int qty) {
            AtomicInteger cell = stock.get(sku);
            while (true) {
                int have = cell.get();
                if (have < qty) {
                    return false;
                }
                seam.run();
                if (cell.compareAndSet(have, have - qty)) {
                    return true;
                }
            }
        }
        public int available(String sku) { return stock.get(sku).get(); }
    }

    /** Returns {failing rounds, oversold units, lost updates}. */
    static int[] attack(Function<Void, Inventory> fresh, ExecutorService pool) throws Exception {
        int failing = 0, oversold = 0, lost = 0;
        for (int r = 0; r < ROUNDS; r++) {
            Inventory inv = fresh.apply(null);
            CyclicBarrier start = new CyclicBarrier(THREADS);
            List<Future<Boolean>> calls = new ArrayList<>();
            for (int t = 0; t < THREADS; t++) {
                calls.add(pool.submit(() -> {
                    start.await();                                     // all threads leave the barrier together
                    return inv.reserve("sku-1", 1);
                }));
            }
            int successes = 0;
            for (Future<Boolean> f : calls) {
                successes += f.get() ? 1 : 0;
            }
            int over = Math.max(0, successes - STOCK);
            int lostUpdates = (STOCK - successes) - inv.available("sku-1");       // stock that vanished or reappeared
            if (over > 0 || lostUpdates != 0) {                                   // INV: successes <= stock, books balance
                failing++;
                oversold += over;
                lost += Math.abs(lostUpdates);
            }
        }
        return new int[] {failing, oversold, lost};
    }

    public static void main(String[] args) throws Exception {
        System.out.printf("%d threads x %d rounds, stock %d per round; invariant: successes <= stock and available == "
                + "stock - successes%n", THREADS, ROUNDS, STOCK);
        try (ExecutorService pool = Executors.newFixedThreadPool(THREADS)) {
            Object[][] variants = {
                    {"check-then-act, seam widened", (Function<Void, Inventory>) v -> new CheckThenAct(WIDEN), true},
                    {"check-then-act, no seam", (Function<Void, Inventory>) v -> new CheckThenAct(NO_SEAM), true},
                    {"ConcurrentHashMap.compute", (Function<Void, Inventory>) v -> new AtomicCompute(), false},
                    {"CAS loop, seam widened", (Function<Void, Inventory>) v -> new CasLoop(WIDEN), false},
            };
            for (Object[] v : variants) {
                @SuppressWarnings("unchecked")
                Function<Void, Inventory> factory = (Function<Void, Inventory>) v[1];
                int[] res = attack(factory, pool);
                String verdict = (boolean) v[2]
                        ? (res[0] > 0 ? "test CATCHES the bug" : "test MISSED the bug (window too narrow)")
                        : (res[0] == 0 ? "invariant holds" : "FIX IS BROKEN");
                System.out.printf("  %-30s failing rounds %3d/%d, oversold %4d, lost updates %4d -> %s%n",
                        v[0], res[0], ROUNDS, res[1], res[2], verdict);
            }
        }
    }
}
```

**Output (verified; the two check-then-act lines vary by run):**


### L2 · `ArchRuleLab.java`

**What it shows.**
- A five-class hexagonal codebase, clean and legacy variants, written and compiled in-process (`javax.tools`) and imported with `ClassFileImporter`.
- A layered-architecture rule and a domain-purity rule: clean passes, legacy fails, with ArchUnit's exact violation descriptions.
- The `FreezingArchRule` ratchet over an in-memory `ViolationStore`: record, block a new violation, shrink when one is fixed.

**What it does not show.** ArchUnit's JUnit 6 integration (`@AnalyzeClasses`, `@ArchTest`, which is how you'd write it in a repo), or the default text store's configuration (`archunit.properties`).

Run: `java -cp archunit-1.5.1.jar:slf4j-api.jar ArchRuleLab.java` (JDK 21+; needs `javax.tools`, so a JDK, not a JRE).

```java
// ArchRuleLab.java - T6's fences on real bytecode with ArchUnit 1.5.1. The lab writes a small hexagonal codebase (clean,
// then a legacy variant with two violations), compiles it in-process with javax.tools, imports the classes, and runs:
// the layer rules (clean passes, legacy fails); FreezingArchRule over an in-memory store (legacy passes with its debt
// recorded; one NEW violation fails alone; fixing an old one shrinks the store) - the legacy-refactoring ratchet.
import com.tngtech.archunit.core.domain.JavaClasses;
import com.tngtech.archunit.core.importer.ClassFileImporter;
import com.tngtech.archunit.lang.ArchRule;
import com.tngtech.archunit.lang.EvaluationResult;
import com.tngtech.archunit.library.freeze.FreezingArchRule;
import com.tngtech.archunit.library.freeze.ViolationStore;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Properties;
import javax.tools.ToolProvider;

import static com.tngtech.archunit.lang.syntax.ArchRuleDefinition.noClasses;
import static com.tngtech.archunit.library.Architectures.layeredArchitecture;

public final class ArchRuleLab {
    static final String P = "com.acme.orders";

    static final ArchRule LAYERS = layeredArchitecture().consideringOnlyDependenciesInLayers()
            .layer("Domain").definedBy(P + ".domain..")
            .layer("Application").definedBy(P + ".application..")
            .layer("Adapter").definedBy(P + ".adapter..")
            .whereLayer("Adapter").mayNotBeAccessedByAnyLayer()
            .whereLayer("Application").mayOnlyBeAccessedByLayers("Adapter")
            .whereLayer("Domain").mayOnlyBeAccessedByLayers("Application", "Adapter");

    static final ArchRule PURE_DOMAIN = noClasses().that().resideInAPackage(P + ".domain..")
            .should().dependOnClassesThat().resideInAnyPackage("java.sql..", "javax.sql..")
            .as("domain must not touch JDBC");

    static final Map<String, String> CLEAN = Map.of(
            "domain/Order.java", "package com.acme.orders.domain; public record Order(long id, long amountCents) {"
                    + " public Order { if (amountCents <= 0) throw new IllegalArgumentException(\"amount\"); } }",
            "application/PlaceOrder.java", "package com.acme.orders.application; import com.acme.orders.domain.Order;"
                    + " public final class PlaceOrder { private final OrderStore store;"
                    + " public PlaceOrder(OrderStore store) { this.store = store; }"
                    + " public Order place(long id, long cents) { Order o = new Order(id, cents); store.save(o); return o; } }",
            "application/OrderStore.java", "package com.acme.orders.application; import com.acme.orders.domain.Order;"
                    + " public interface OrderStore { void save(Order o); }",
            "adapter/JdbcOrderStore.java", "package com.acme.orders.adapter; import com.acme.orders.application.OrderStore;"
                    + " import com.acme.orders.domain.Order; public final class JdbcOrderStore implements OrderStore {"
                    + " public void save(Order o) { new OrderRow(o.id(), o.amountCents()); } }",
            "adapter/OrderRow.java", "package com.acme.orders.adapter; public record OrderRow(long id, long cents) {}");

    static Map<String, String> with(Map<String, String> base, Map<String, String> changes) {
        Map<String, String> m = new HashMap<>(base);
        m.putAll(changes);
        return m;
    }

    static final Map<String, String> LEGACY = with(CLEAN, Map.of(
            "domain/Order.java", "package com.acme.orders.domain; public record Order(long id, long amountCents) {"
                    + " public com.acme.orders.adapter.OrderRow toRow() { return new com.acme.orders.adapter.OrderRow(id, amountCents); } }",
            "domain/OrderPricing.java", "package com.acme.orders.domain; public final class OrderPricing {"
                    + " public long price(java.sql.Connection c) throws java.sql.SQLException { return c.getNetworkTimeout(); } }"));

    static final Map<String, String> LEGACY_PLUS_NEW = with(LEGACY, Map.of(
            "domain/Refund.java", "package com.acme.orders.domain; public final class Refund {"
                    + " public Object audit() { return new com.acme.orders.application.PlaceOrder(null); } }"));

    static final Map<String, String> LEGACY_ONE_FIXED = with(LEGACY, Map.of(
            "domain/Order.java", CLEAN.get("domain/Order.java")));

    static JavaClasses compile(String name, Map<String, String> sources) throws IOException {
        Path root = Files.createTempDirectory("archlab-" + name);
        List<String> args = new ArrayList<>(List.of("-d", root.resolve("classes").toString(), "--release", "21"));
        for (Map.Entry<String, String> e : sources.entrySet()) {
            Path file = root.resolve("src/com/acme/orders").resolve(e.getKey());
            Files.createDirectories(file.getParent());
            Files.writeString(file, e.getValue());
            args.add(file.toString());
        }
        int rc = ToolProvider.getSystemJavaCompiler().run(null, null, null, args.toArray(String[]::new));
        if (rc != 0) {
            throw new IllegalStateException("compile failed: " + name);
        }
        return new ClassFileImporter().importPath(root.resolve("classes"));
    }

    /** An in-memory ViolationStore; in a repository, ArchUnit's default text store under archunit_store/ is committed. */
    static final class MemoryStore implements ViolationStore {
        final Map<String, List<String>> saved = new HashMap<>();
        public void initialize(Properties properties) {}
        public boolean contains(ArchRule rule) { return saved.containsKey(rule.getDescription()); }
        public void save(ArchRule rule, List<String> violations) { saved.put(rule.getDescription(), List.copyOf(violations)); }
        public List<String> getViolations(ArchRule rule) { return saved.getOrDefault(rule.getDescription(), List.of()); }
        int size() { return saved.values().stream().mapToInt(List::size).sum(); }
    }

    static String verdict(EvaluationResult r) {
        if (!r.hasViolation()) {
            return "PASS";
        }
        List<String> details = r.getFailureReport().getDetails();
        return "FAIL (" + details.size() + "): " + String.join(" | ", details.stream()
                .map(d -> d.replaceAll(" in \\(\\w+\\.java:\\d+\\)", "")).sorted().toList());
    }

    public static void main(String[] args) throws IOException {
        JavaClasses clean = compile("clean", CLEAN), legacy = compile("legacy", LEGACY);
        System.out.println("1. Layer and purity rules");
        for (ArchRule rule : List.of(LAYERS, PURE_DOMAIN)) {
            String name = rule == LAYERS ? "layers" : "pure domain";
            System.out.println("  clean  " + name + ": " + verdict(rule.evaluate(clean)));
            System.out.println("  legacy " + name + ": " + verdict(rule.evaluate(legacy)));
        }
        System.out.println("2. Frozen (the legacy ratchet)");
        MemoryStore store = new MemoryStore();
        ArchRule frozen = FreezingArchRule.freeze(LAYERS.as("layers")).persistIn(store);
        ArchRule frozenPure = FreezingArchRule.freeze(PURE_DOMAIN).persistIn(store);
        System.out.println("  legacy, first run:        " + verdict(frozen.evaluate(legacy)) + ", "
                + verdict(frozenPure.evaluate(legacy)) + "; store holds " + store.size() + " violation(s)");
        JavaClasses plusNew = compile("plusnew", LEGACY_PLUS_NEW);
        System.out.println("  legacy + new Refund:      " + verdict(frozen.evaluate(plusNew)));
        JavaClasses oneFixed = compile("fixed", LEGACY_ONE_FIXED);
        System.out.println("  legacy, Order.toRow gone: " + verdict(frozen.evaluate(oneFixed)) + "; store holds "
                + store.size() + " violation(s)");
    }
}
```

## 4. Failure modes

| # | Symptom | Root cause | Fix |
|---|---|---|---|
| F1 | The concurrency test is green, production oversells | Test ran once, or the window was too narrow | Barrier + R rounds + seam (rules 2–3; L1) |
| F2 | The "fix" adds `synchronized` everywhere, throughput collapses | No narrowest-fix requirement, no benchmark | T5 anti-goal 3 + JMH (INV-CONC-4) |
| F3 | The benchmark shows a 10× gain that vanishes in production | One fork, no warmup, dead-code elimination | JMH forks/warmup/`Blackhole`; report the error |
| F4 | The refactor changed behaviour and nobody noticed | No characterization tests, or snapshots updated silently | INV-LEG-1/2; behaviour changes in separate commits |
| F5 | ArchUnit rule added, build red with 400 violations, rule deleted | No freeze | `FreezingArchRule` (L2) |
| F6 | Debt store grows quietly | Store regenerated or edited | Store committed; diff must only remove lines |
| F7 | Integration tests pass on H2, fail on PostgreSQL | Dialect, NULLs, isolation | Testcontainers + `@ServiceConnection` (INV-LEG-4) |
| F8 | CI flakes on `latest` images | Unpinned container tags | Pinned tags (INV-LEG-5) |

## 5. Staff-level drills

<details><summary><b>D1 · "Claude wrote a concurrency test with 100 threads and it passes. Ship it?"</b></summary>

**Naive answer.** 100 threads is a lot of concurrency; if it passes, it's thread-safe.

**Why it fails.** Thread count isn't interleaving coverage. Without a barrier the threads start milliseconds apart and barely overlap. Without a seam, the read-write window is nanoseconds wide. L1's no-seam variant caught a *real* bug in 1–2 of 200 rounds.

**Staff answer.** Ask for the failing-before evidence, INV-CONC-2. Revert the fix and run the test; it must fail. If it doesn't, add the barrier, the rounds and the seam until it does. Only then is a green run meaningful.
</details>

<details><summary><b>D2 · "We want hexagonal architecture, but the codebase has hundreds of violations."</b></summary>

**Staff answer.** Write the rule you want, freeze it, and commit the store.
- Nothing new can violate it from today: the CI gate.
- Every refactoring PR shows the store shrinking: the metric.
- No big-bang migration is needed.

L2 is the whole mechanism in 20 lines. Give T6 the frozen rule as the definition of done per step: "the store diff only removes lines".
</details>

<details><summary><b>D3 · "Characterization tests will lock in bugs."</b></summary>

**Staff answer.** Yes, deliberately and temporarily. They lock in *current* behaviour so that refactoring commits can be proven behaviour-neutral. Fixing a bug then becomes a separate, reviewed commit that changes one snapshot with a stated reason.

The alternative is a refactor that also changes behaviour in ways nobody chose, which is how legacy rewrites cause incidents.
</details>

## 6. Checklist

- [ ] Every race test: barrier, R rounds, per-round invariant, a seam where needed, shown failing before the fix.
- [ ] Fixes are the narrowest that hold, and are benchmarked with JMH (forks, warmup, error reported).
- [ ] Legacy work starts with characterization tests on real infrastructure, green on unchanged code.
- [ ] Target architecture as ArchUnit rules, frozen; the store committed and only ever shrinking.
- [ ] Testcontainers via `@ServiceConnection`, pinned tags, no H2; refactorings and behaviour changes in separate commits.
