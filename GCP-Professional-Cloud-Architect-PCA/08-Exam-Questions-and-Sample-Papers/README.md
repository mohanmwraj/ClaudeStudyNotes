## How the questions are built

* **Format:** single-answer questions have 4 options; "Select TWO" has 5 options; "Select THREE" has 6. That matches the real exam's multiple choice and multiple select styles.
* **Labels:** each drill question is labelled with its exam-guide objective (Task 1.1 … 6.6), and each mock question with its section and objective. The real exam doesn't label questions; the labels are here to help your review.
* **Explanations:** every option is explained (**correct** or **wrong**, and why). A **Why** line names the governing first principles (P1–P16 from [02-first-principles-mental-models.md](../00-Exam-Strategy-and-First-Principles/02-first-principles-mental-models.md)), and each answer links an official reference.
* **Mock composition:** each mock mirrors the official weighting, with 13 / 9 / 9 / 7 / 6 / 6 questions for Sections 1–6. Each includes **12 case-study questions (24%)** from two case studies, and 6 multiple-select questions. Correct answers are balanced across A–D.
* **Current product names:** where a product was renamed in 2024–2026, questions use the current name, usually with the former name in brackets. Learn both ([05-product-name-rosetta.md](../00-Exam-Strategy-and-First-Principles/05-product-name-rosetta.md)).

## How to use them

1. **Drills:** untimed, open-book allowed on the first pass. Read every explanation, then log each miss in a three-column file: *question · the constraint I missed · the principle*.
2. **Case-study drill:** closed book, after studying the four breakdowns. Aim for at least 80%.
3. **Mocks:** strictly timed (120 minutes), closed book, on separate days. Score by domain; below 70% in any domain means re-reading that folder before the next mock.
4. **Official sample questions:** take Google's [official sample questions](https://docs.google.com/forms/d/e/1FAIpQLSf54f7FbtSJcXUY6-DUHfBG31jZ3pujgb8-a5io_9biJsNpqg/viewform) once, at the end, as an independent calibration.

## Readiness

| Signal | Ready |
|---|---|
| Each domain drill | ≥ 80% |
| Case-study drill | ≥ 80% |
| Two different mocks | ≥ 40/50 each |

Google doesn't publish a passing score, so these thresholds are deliberately conservative.
