# 09 — Graphs: consolidated problem ladder

99 problems from Codeforces, CSES and AtCoder, grouped by rating band, easiest first within a band, then a LeetCode
section. Ratings: Codeforces values are official; CSES ratings are estimates (≈, est.); AtCoder values are the
difficulty estimates published by AtCoder Problems (≈, est.). Hints name the topic only — the matching topic file is given
in brackets: [01] representation/BFS/DFS, [02] shortest paths, [03] MST, [04] topological sort/DAG DP, [05] SCC,
[06] bridges/BCC, [07] 2-SAT, [08] Euler, [09] bipartite/cycles, [10] functional/special graphs.

Suggested use: finish the ≤1700 bands before Master-track contests; from 1900 on, solve a problem per day without looking
at tags, then classify it into a file here afterwards.
